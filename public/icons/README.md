# Pressing — Palette SVG Luxe Monochrome

Version raffinée de la bibliothèque d'icônes pour une application de gestion de pressing.

## Direction artistique
- Noir profond `#111111`
- Blanc `#FFFFFF`
- Traits fins : 1.55 px
- Coins et extrémités arrondis
- ViewBox 24×24
- Fond transparent sur les icônes individuelles
- Style adapté aux interfaces premium/luxe

## Fichiers
- `*.svg` : 106 icônes individuelles
- `pressing-luxe-sprite.svg` : sprite complet
- `palette-preview.svg` : planche de présentation
- `PressingLuxeIcon.jsx` : composant React
- `pressing-luxe.css` : variables CSS et style
- `CATALOGUE.json` : catalogue

## Exemple
```jsx
<PressingLuxeIcon name="washing-machine" size={24} />
<PressingLuxeIcon name="order" size={22} />
<PressingLuxeIcon name="mobile-money" size={24} />
```
